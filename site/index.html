02 / DATA QUALITY

A projected ratio must still reconcile

The original projected operating margins and P/E ratios differ from ratios calculated using the same projected line items. We preserve the original values and show the arithmetic discrepancy.

Operating margin = operating profit ÷ sales × 100
P/E = price ÷ EPS

If numerator and denominator grow at the same rate, their ratio stays constant. Growing a ratio independently can create an inconsistent projection. These checks concern the assignment, not an allegation about company reporting.
